# 덜 붐비는 오름 찾기

제주관광빅데이터플랫폼(data.ijto.or.kr)의 「오름별 차량 도착 수」(티맵 내비게이션, 2021-01~2026-09) 데이터로
관광객 도착이 몇몇 오름에 몰리는 정도를 재고, 가려던 오름 대신 갈 만한 가까운 오름과 한산한 달을 보여 주는 정적 웹 페이지를 만들었습니다.

- `analyze.py`: 분석과 추천 데이터 생성 (pandas, matplotlib)
- `page_template.html` → `docs/index.html`: 추천 페이지 (HTML 한 장, 외부 요청 없음. 파일을 브라우저로 열면 동작)
- `out/summary.json`, `out/recommend.json`, `out/fig*.png`: 분석 결과
- `data/oreum_2021_2026.csv`: 플랫폼 「데이터 픽」에서 받은 원본 CSV (제주관광공사, 공공누리 제1유형)

## 실행

```
pip install pandas matplotlib
python analyze.py
open docs/index.html
```

## 분석 결과 요약 (2025년 기준)

- 관광객 내비 도착 가운데 상위 5개 오름(금오름, 새별오름, 용눈이오름, 서우봉, 군산오름) 비중이 65.7%입니다. 2021년 70.8%, 2023년 66.5%, 2024년 67.7%였습니다.
- 10~11월은 상위 5개 오름의 연간 관광객 도착 중 24.6%가 몰리는 달입니다(나머지 오름은 18.0%). 2023~2025년 합계 기준입니다.
- 상위 15개 오름 중 11곳은 같은 읍면이나 맞닿은 읍면에서 관광객 비중과 관광객 도착 수가 모두 더 낮은 대안을 찾았습니다(연 도착 1,000건 이상 조건).
  예: 새별오름(관광객 58%) → 큰노꼬메오름(32%), 궷물오름(52%), 바리메오름(52%).

## 한계

- 내비게이션 도착 기록이라 실제 방문객 수가 아니고, 티맵 이용자만 잡힙니다.
- 플랫폼 안내대로 2026년 1월부터 도착 집계 로직이 바뀌어 2026년 수치는 이전과 바로 비교하지 않았습니다. 추천은 2025년까지만 씁니다.
- 대안 오름의 탐방로 난이도, 주차, 휴식년제 같은 현장 조건은 반영하지 못했습니다. 다녀오기 전에 현장 정보를 확인해야 합니다.
- 맞닿은 읍면 목록은 코드 안 `NEIGHBORS`에 직접 적었습니다.
